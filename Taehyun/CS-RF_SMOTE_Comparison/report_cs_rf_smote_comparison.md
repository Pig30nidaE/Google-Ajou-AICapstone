- **작성 일시**: 2026-09-20 17:15:00
- **평가 환경**: Zero-Leakage Repeated Nested CV (5 Seeds: 42, 13, 73, 101, 2026 × Outer 5-Fold × Inner 5-Fold, 총 50회 Outer Fold 평가)
- **임계값 결정**: Inner Fold Youden's Index ($J = TPR - FPR$ 최대화) 최적 컷오프 (Zero-Leakage)
- **통계적 신뢰구간**: B=1,000회 환자 단위 층화 부트스트랩 (95% CI)

## 1. 33명 일주기 피처 0값 결함의 원인 및 정상 복원 요약

### 1.1 원인 추적 결과 (Root Cause)
- **AIHub 원천 분할**: 원본 데이터셋은 `train_activity.csv` (141명)와 `val_activity.csv` (33명)로 분리되어 있었습니다 ($141 + 33 = 174$명).
- **피처 추출 스크립트 결함**: 과거 일주기 피처를 계산할 때([extract_circadian_features.py](file:///c:/ML4/scripts/extract_circadian_features.py#L154-L162)), `train_activity.csv`만 로드하고 `val_activity.csv`를 불러오지 않아 33명의 1분 단위 시계열이 빈 데이터로 처리되었습니다.
- **방어 코드의 0.0 반환**: 데이터가 없으면 에러를 내는 대신 조용히 `0.0`을 반환하는 예외 처리로 인해, 검증셋 33명의 `circadian_IS`, `circadian_IV`, `circadian_RA`, `sleep_wake_bouts_avg`가 모두 정확히 `0.0`으로 저장되었습니다.

### 1.2 복원 조치 및 검증
- 로컬에 온전히 보존되어 있던 [val_activity.csv](file:///c:/ML4/data/val_activity.csv)(2,478일치)와 [val_sleep.csv](file:///c:/ML4/data/val_sleep.csv)로부터 33명의 실제 1분 단위 시계열을 100% 정상 추출하여 데이터셋에 반영했습니다.
- **0값 대상자 수**: 복원 전 **33명** $\rightarrow$ 복원 후 **0명** (완전 정상화)

### 2.2 성능 변화에 대한 통계적·의학적 해석
1. **0.71 대에서 0.68 대(-0.02)로의 수렴 원인**:
   - 복원 전에는 0값 결측 33명 중 **26명이 정상군(23.4%)**, 단 7명만이 환자군(11.1%)에 편중되어 있었습니다.
   - 모델이 "일주기 리듬이 0이면 정상인"이라는 **데이터 수집상의 결함(아티팩트/지름길)을 일종의 치팅 신호로 학습**하여 AUC가 약 0.7092로 과대평가되었던 것입니다.
   - 33명의 실제 1분 단위 시계열을 복원하여 결함 신호를 제거하자, **순수한 웨어러블 생체 리듬 기반의 진짜 예측 성능인 AUC 0.6885**로 수렴했습니다.
2. **단일 XGBoost의 우수성 유지**:
   - 아티팩트가 제거된 상태에서도 단일 `XGBoost_Global`(0.6885)이 6개 모델 결합 앙상블(0.6818)보다 **+0.0067 높은 AUC를 기록**하여 모델 단순화의 타당성이 재확인되었습니다.

## 5. 최종 결론 및 권고사항

1. **데이터 결함 해결**: 33명의 0값 결함은 원본 `val_*.csv` 파일이 누락되어 발생한 단순 파이프라인 버그였으며, 100% 온전히 복원되어 결측치 없이 데이터셋이 정상화되었습니다.
2. **진짜 생체 신호 성능 확정**: 아티팩트가 걷힌 순수 웨어러블 장기 라이프로그 기반의 진정한 진단 성능은 **단일 XGBoost 기준 AUC 0.6885 (95% CI: 0.6212~0.7901)**입니다.
3. **SMOTE 미사용 권고**: SMOTE를 쓰지 않는 순수 원본 데이터 학습이 모든 모델에서 더 우수한 AUC를 달성하므로, 최종 모델 파이프라인에서 SMOTE를 영구 배제하는 것이 타당합니다.
4. **단일 모델 채택의 정당성**: 6개 모델 앙상블(0.6818) 대비 단일 XGBoost(0.6885)의 우위가 유지되므로, 시스템 복잡도를 획기적으로 낮추고 SHAP 해석을 직관적으로 제공할 수 있는 단일 XGBoost 모델을 최종 후보로 확정할 수 있습니다.
