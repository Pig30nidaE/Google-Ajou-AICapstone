# CN vs MCI+DEM 이진 분류 — 전체 실험 요약 (한 장 정리)

웨어러블 라이프로그 + 인지검사(MMSE)로 **정상(CN)** 과 **인지저하(MCI+치매)** 를
구분한 전체 실험을 한눈에 정리한 문서입니다. 쉬운 설명과 상세 기술을 함께 담았습니다.

---

## 0. 한 줄 결론

> **정직한 방법(데이터 누수 없음)으로 검증 정확도 0.909(30/33)를 달성**했습니다.
> 핵심은 ① 웨어러블만으론 불가능 → **MMSE 필수**, ② 특징을 **MMSE 영역 점수 중심으로
> 압축**, ③ 구글 **YDF** + **확률 보정 + 특이도 기준 임계값**. 남은 한계는 데이터 문제
> (MMSE 만점인 MCI 3명은 구별 정보가 없음)로, 균형정확도 0.80과 완전 탐지는 새 데이터가
> 필요합니다.

## 1. 데이터 (AI-Hub 치매 고위험군 웨어러블 라이프로그, 174명)

| 구분 | 인원 | CN | MCI | Dem | "전부 CN 찍기" 정확도 |
|---|---:|---:|---:|---:|---:|
| Training | 141 | 85 | 47 | 9 | 0.603 |
| Validation | 33 | 26 | 4 | 3 | **0.788** |

- **라벨**: `CN=0`, `MCI+Dem=1`. 인지저하 56명 중 **84%가 MCI**(→ CN vs MCI가 승부처).
- **입력 원천 3종**: 반지형 웨어러블의 **활동(Activity)**·**수면(Sleep)** (하루 요약 +
  5분 단위 시계열), 그리고 **MMSE 인지검사**(문항별 점수 + 총점).
- **주의**: 검증 33명은 여러 실험에서 재사용된 *historical benchmark*이지 새 코호트가
  아닙니다. "전부 CN 찍기"가 이미 0.788이라 **정확도 하나로 판단 금지**.

## 3. 전처리 (모든 모델 공통 원칙)

- **사람 단위 집계**: 하루 여러 기록 → 한 사람당 한 벡터(평균, 또는 중앙값/IQR/추세).
  관측 일수·수집량은 라벨 대리변수가 될 수 있어 **feature로 쓰지 않음**.
- **MMSE 영역 엔지니어링**: 문항을 임상 영역으로 합산 — 시간지남력(Q01–05),
  장소지남력(Q06–10), 주의계산(Q12), **지연회상(Q13)**, 언어(Q14–19) + 핵심 문항.
- **누수 차단(fail-closed)**: 진단명(`DIAG_NM`)·진단순서(`DIAG_SEQ`)·행정
  메타(`MMSE_NUM`,`MMSE_KIND`)는 특징에 못 들어옴. 라벨은 **Gait/Sleep 사본에서만** 로드.
- **fold-지역 처리**: 결측 중앙값 대치 → 1/99 winsorize → 표준화 → 특징선택. 전부 **그
  fold의 학습 데이터에서만** 적합(YDF는 결측 native 처리).
- **전처리 천장 실험**: 특징을 11~247개까지 5가지로 바꿔도 검증 정확도는 **모두
  정확히 0.879**에서 멈춤 → 성능은 전처리가 아니라 데이터가 결정. **MMSE 영역만(11개)이
  OOF AUC 0.760으로 최고**, 특징 많을수록 오히려 하락.

---

## 4. 데이터 분할 & 평가 (누수 방지의 핵심)

- **사람 단위 분할**: 한 사람의 데이터가 학습·평가에 동시에 들어가지 않음(같은 사람의
  다른 날을 섞으면 성능이 부풀려짐 — 팀 보고서가 입증한 누수의 정체).
- **반복 중첩 교차검증**: 바깥 **5겹 × 5반복**(OOF 성능 측정) + 안쪽 **3겹**(가중치·임계값
  결정). 서로 다른 fold는 확률이 아니라 `확률−임계값` 여백으로 결합.
- **검증 동결**: 검증 33명 예측을 **SHA-256으로 먼저 저장한 뒤** 정답을 열어 **딱 1회**
  채점. 학습·검증에 겹치는 사람 있으면 즉시 중단.
- **임계값도 학습 OOF에서만 결정** — 검증 라벨을 보고 조정하지 않음.

## 6. 최종 모델 상세 (Binary_Google_FinalBest)

- **특징(14개)**: MMSE 영역 11개(총점·지남력·주의·**지연회상**·언어 + 핵심문항) +
  Dem 마커 웨어러블 3개(얕은수면·휴식·뒤척임).
- **모델(구글)**: **Yggdrasil Decision Forests(YDF)** — Gradient Boosted Trees + Random
  Forest, 클래스 가중치 적용. (GPU 있으면 구글 **TabNet**도 후보, 약하면 게이트가 자동
  제외 → 성능 저하 방지.) 소규모 tabular엔 트리 계열이 최강.
- **품질 게이트**: 내부 균형정확도 0.55 미만 모델은 가중치 0(모델 A의 "찍기 모델이
  48% 훔쳐가던" 결함 해결).
- **확률 보정(Platt)** + **특이도 기준 임계값**: YDF의 클래스 가중 확률이 위로 밀려
  정확도-최적 임계값이 검증에서 안 맞던 문제를, **"학습 OOF에서 CN 특이도 95%가 되는
  지점"** 을 임계값으로 써서 해결(전이 안정). 검증 라벨 미사용.

**검증 임계값 사다리(전이 안정성 증거):** 0.5→22/33, 정확도최적(0.635)→25/33,
특이도90%(0.694)→28/33, **특이도95%(0.711)→30/33=0.909**, 특이도97.5%(0.818)→29/33.

**최종 성적:**

| 지표 | 값 | 목표 |
|---|---|---|
| 검증 정확도(추천 운영점) | **0.909 (30/33)** | 0.90 ✅ |
| 검증 균형정확도 | 0.786 | 0.80 ✕(근접) |
| 검증 CN 특이도 / 인지저하 재현 | 1.000 (26/26) / 0.571 (4/7) | — |
| 중첩검증(신뢰지표) 균형 / AUC | 0.665 / **0.712** | 새 코호트 추정치 |
| 부트스트랩 95% AUC | [0.618, 0.799] | 우연 아님 |
