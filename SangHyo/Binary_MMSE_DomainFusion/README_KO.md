# Binary_MMSE_DomainFusion (모델 1 — 모델 A·B에서 배운 개선판)

## 한 줄 요약

이전 두 모델(웨어러블만 / 웨어러블+MMSE)의 결과를 분석해, **MMSE를 영역별로
가공한 특징 + 엄선한 웨어러블 특징**만 쓰고, 모델 A에서 발견한 **앙상블
가중치 결함을 고친** 개선 모델입니다. `CN` vs `MCI+DEM` 이진 분류입니다.

## 이전 결과에서 무엇을 배웠나

- **웨어러블만으로는 거의 못 맞힘**(모델 A: 중첩검증 AUC ≈0.52, 찍기 수준).
- **MMSE를 넣으면 확실히 좋아짐**(모델 B: AUC ≈0.70). 성능은 사실상 MMSE가
  만든다.
- 모델 A의 문제: 모든 모델이 찍기일 때 가중치 정규화가 **근소하게 큰 모델
  (신경망)에 48%를 몰아줘** 오히려 성능을 깎았다.
- 모델 B의 문제: 168개나 되는 웨어러블 요약 특징이 **노이즈**로 MMSE 신호를
  희석했다.

## EDA로 확인한 핵심 (이 모델의 근거)

팀 EDA와 자체 분석 결과:

- **CN vs MCI**(어려운 경계, 인지저하 56명 중 47명이 MCI)는 **MMSE 지연 회상
  문항**으로만 갈린다. 방향성 제거 AUC: 지연회상 영역합 `recall` **0.704**,
  `TOTAL` 0.695, `Q13_3`·`Q13_2` 0.67. 기억등록(Q11)은 전원 만점이라 무용 →
  제거.
- **웨어러블은 CN vs MCI를 못 가르지만(≈0.60), 치매(Dem)는 잘 잡는다**
  (얕은수면 0.80, 휴식 0.78, 뒤척임 0.77, 하루목표달성 0.74).

## 이 모델이 쓰는 특징 (약 30개)

- **MMSE 영역 점수(10개)**: 총점, 시간지남력·장소지남력·주의계산·지연회상·언어
  영역합 + 핵심 문항(Q13_2, Q13_3, Q12_5, Q03, Q09). (진단명/진단순서/행정
  메타는 fail-closed로 제외, 라벨은 Gait/Sleep 사본에서만 로드)
- **엄선 웨어러블 사람 단위 평균(약 20개)**: 활동점수·하루목표달성·운동빈도/량·
  걸음수·휴식·비활동·저강도·이동량 + 수면시간·각성·얕은수면·깊은수면·뒤척임·
  효율·깊은수면점수·호흡수·심박(평균/최저)·HRV.

## 무엇을 고쳤나

- **품질 게이트**: 각 모델은 내부 교차검증 균형정확도가 **0.55를 실제로 넘을
  때만** 앙상블에 참여합니다. 못 넘으면 가중치 0. 다 못 넘으면 노이즈를 섞지
  않고 **가장 나은 단일 모델**로 물러섭니다. (모델 A의 결함 해결)
- **노이즈 제거**: 168개 요약 대신 EDA로 검증된 소수 특징만 사용.
- **임계값 3종 보고**: 0.5 / 균형정확도 최대 / 정확도 최대 세 가지로 평가.

## 모델 구성

- `gbt`(HistGradientBoosting) + `logreg`(L2 로지스틱) + `rf`(랜덤포레스트),
  모두 클래스 가중치 적용. fold 학습 데이터에서만 대치·정규화·특징선택.
- 사람 단위 **5-겹 × 5-반복 중첩 교차검증**, 검증 33명은 예측 동결(SHA-256) 후
  1회만 채점.

## 목표와 정직한 기대치

- 목표: 정확도 **0.90**, 균형정확도 **0.80**.
- 로컬 참고값(전처리·배선 검증용, 실제 값은 Colab에서 확인): **중첩검증 AUC
  ≈0.71**, 균형정확도 ≈0.64(임계값 0.5)~0.69(정확도 임계값), 검증 33명
  정확도 **최대 0.879**, 균형정확도 ≈0.71~0.73. 모델 B(AUC 0.70, 검증 0.788)
  보다 개선됐습니다.
- 다만 **가장 믿을 값인 중첩검증 균형정확도는 아직 0.80 미만**입니다. 이유는
  임상적으로 **MCI의 MMSE 점수가 정상과 겹치기** 때문이며, 이는 누수 없이는
  넘기 어려운 근본 한계입니다. 검증 33명 정확도 0.879는 작은 표본의 우호적
  결과로, 과대 해석하지 마세요.
