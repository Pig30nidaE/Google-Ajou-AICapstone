# CN vs MCI+Dem 이진분류 최종 모델 제안

최종 갱신: **2026-07-30**

## 1. 선정 기준과 요약

이 문서는 `SangHyo/`에 저장된 실험 결과를 비교해, **MMSE를 사용하는 경우와
사용하지 않는 경우에 가장 성능이 좋았던 모델을 하나씩 제안**한다.

- 과제는 `CN=0`, `MCI 또는 Dem=1`인 동일한 이진분류다.
- 학습 데이터는 141명(CN 85명 / MCI 47명 / Dem 9명)이다.
- 성능은 한 사람의 기록이 학습용과 평가용에 동시에 들어가지 않도록 나눈 뒤
  계산한 **ROC-AUC**로 비교한다. 표의 `Subject-mean OOF ROC-AUC`는 각 사람을
  학습에서 제외한 상태로 얻은 예측을 모아 계산한 값이다.
- 간단한 실행 확인용 실험, 끝나지 않은 실험, 하루나 구간을 무작위로 섞어
  사람 정보가 겹칠 수 있는 실험, 그리고 다른 분류 과제는 비교에서 제외했다.
- 같은 평가 결과를 보며 모델을 고르는 방식(non-nested)은 허용했다. 다만
  평가 대상자의 정답을 미리 보고 입력 변수를 고르거나 모델을 학습하는
  **직접적인 데이터 누수**가 있는 결과는 제외했다.
- 여러 번 분할한 실험은 한 사람에게서 나온 예측을 먼저 평균한 ROC-AUC를
  대표값으로 삼고, 분할 반복별 평균도 함께 적었다.

| 구분 | 제안 모델 | 사람별 예측 평균 ROC-AUC | 분할 반복별 AUC 평균 |
| --- | --- | ---: | ---: |
| **MMSE 포함** | Google YDF Sparse-Oblique GBT + RF ECDF ensemble | **0.7834** | 0.7662 |
| **MMSE 미포함** | 28일·8개 입력 Sequence Transformer | **0.6293** | 0.5955 |

MMSE를 사용한 Gemma 인지 특징 모델도 0.7817로 비슷한 성능을 냈지만, Google
YDF 모델의 0.7834가 조금 더 높았다. MMSE를 사용하지 않는 경우에는 이전
Transformer의 0.6254보다 최근 재실행 결과인 0.6293이 근소하게 높았다.

> `Binary_Google_OrdinalStable`의 0.8103과
> `Binary_Google_MaxAUC_Tuned`의 0.8017은 실제 성능보다 높게 보일 수 있는지
> 확인하려고 의도적으로 만든 참고값이다. 특히 0.8103은 전체 141명의 정답을
> 본 뒤 상위 25개 입력 변수를 골랐기 때문에, 평가 대상자의 정답이 변수
> 선택에 직접 영향을 준다. 따라서 두 값은 최고 모델 선정에서 제외했다.
> 같은 실험에서 직접 누수 없이 계산한 성능은 각각 0.7569와 0.7172다.

## 2. MMSE 포함 모델

### 제안 모델

**Google YDF 두 모델 결합형(2-component ensemble)**

1. `oblique_all151_top25`: 가중치 **0.62995**
2. `rf_mmse39_d6`: 가중치 **0.37005**

원래 실험이 자동으로 고른 최종 모델은 세 모델을 결합한 형태다. 하지만 세 번째
모델의 비중은 약 1%에 불과하고, 이를 빼도 ROC-AUC가 0.783403으로 같았다.
따라서 성능은 유지하면서 구성이 더 간단한 위 두 모델 결합형을 제안한다.

### 전처리 방식

- 한 사람의 데이터를 한 행으로 정리한다.
- MMSE에서는 총점, 6개 인지영역 점수, 30개 문항, 실패 문항 수, 회상 저하
  정도를 포함해 총 39개 입력 변수를 만든다.
- 이 39개 MMSE 변수에 활동·수면 변수 112개를 더해 총 151개 변수를 만든다.
  활동·수면 변수에는 평균, 변화 정도, 수면 단계 비율, 활동 비율, 취침·기상
  시각 등이 포함된다.
- 진단·행정·식별 열과 관측 일수, 행 개수, coverage, missingness 같은 수집량
  지표는 입력에서 제외한다. 이런 값은 질병보다 데이터 수집 환경을 구분할
  가능성이 있기 때문이다.
- Sparse-Oblique GBT는 매 학습 묶음 안에서만 유용한 변수 25개를 고른다.
  서로 지나치게 비슷한 변수는 하나만 남긴다.
- Random Forest는 39개 MMSE 변수를 모두 사용한다.
- YDF 모델이 비어 있는 값을 자체적으로 처리하므로, 전체 데이터를 미리 채우거나
  표준화하지 않는다.
- 두 모델의 출력 범위를 맞춘 뒤 각각 약 63%, 37%의 비율로 합쳐 최종 점수를
  만든다. 이 변환 기준도 평가 대상자가 아닌 학습 데이터에서만 구한다.

### 데이터 분할 방식

- 141명을 진단 비율이 비슷하도록 5개 묶음으로 나누고, 이 과정을 다른
  무작위 조건으로 5번 반복했다.
- 한 번의 반복에서 각 사람은 네 묶음으로 학습한 모델의 평가 대상이 정확히
  한 번 된다.
- 같은 조건에서 비교할 수 있도록 모든 후보 모델에 동일한 사람 분할을 썼다.
- 변수 선택과 비슷한 변수 제거는 매번 학습용 사람만 사용해 처음부터 다시
  수행했다.
- 모델의 우연한 흔들림을 줄이기 위해 후보마다 3개의 무작위 초기값을 사용했다.
- 각 사람에게서 얻은 5개의 평가 점수를 평균한 뒤 최종 ROC-AUC를 계산했다.
- 별도로 제공된 Historical Validation 33명은 이번 실행에서 사용하지 않았다.

### 모델 선택 / 하이퍼파라미터 튜닝

모델을 고를 때는 ROC-AUC만 사용했다. Google YDF의 세 가지 계열
(일반 GBT, Sparse-Oblique GBT, Random Forest)로 만든 9개 후보와, 이들을
단독 또는 여러 개 결합하는 28가지 방법을 같은 분할에서 비교했다.

후보와 결합 비율을 같은 평가 결과를 보며 정했기 때문에 0.7834는 최종 외부
검증 점수가 아니라 **개발 단계의 성능**이다. 다만 한 사람의 예측을 만들 때는
그 사람의 정답을 학습이나 변수 선택에 사용하지 않았다.

아래 값은 같은 모델을 다시 학습할 수 있도록 남기는 상세 설정이다.

| 구성 모델 | 재현을 위한 상세 설정 |
| --- | --- |
| Sparse-Oblique GBT | `num_trees=600`, `max_depth=3`, `min_examples=12`, `shrinkage=0.05`, `subsample=0.7`, `l2_regularization=0.5`, `num_candidate_attributes_ratio=0.5`, `split_axis=SPARSE_OBLIQUE`, projection exponent `1.5`, density factor `3.0` |
| Random Forest | `num_trees=800`, `max_depth=6`, `min_examples=5`, `num_candidate_attributes_ratio=0.5` |

두 모델의 결합 비율은 ROC-AUC가 가장 높아지도록 4,096가지 조합을 탐색해
`Oblique 0.62995 + RF 0.37005`로 정했다.

### 최종 결론 및 코멘트

- 사람별 예측을 평균한 ROC-AUC: **0.783403**
- 분할 반복별 AUC 평균: **0.766197**
- 분할 반복별 AUC 표준편차: **0.014787**
- 직접적인 데이터 누수 점검: 통과
- 원래 세 모델 결합형의 저장 및 재로딩 확인: 통과
- 제안한 두 모델 결합형을 사용할 때는 세 번째 모델을 제외한 배포 파일을
  새로 저장해야 함

직접적인 데이터 누수가 없는 완료 결과 중 MMSE를 사용한 모델로는 가장 높은
ROC-AUC다. Sparse-Oblique 모델이 MMSE와 웨어러블 정보의 복잡한 관계를 찾고,
Random Forest가 MMSE 중심의 판단을 보완한다. 다만 성능 향상의 상당 부분은
MMSE에서 나오므로, 이를 웨어러블만으로 얻은 성능처럼 설명해서는 안 된다.

0.7834는 여러 후보를 비교한 뒤 선택한 **개발 점수**이므로, 아직 완전히 새로운
데이터에서 확인된 성능은 아니다. 다음 평가에서는 모델 구조와 결합 비율을
그대로 고정하고, 새로운 사람 분할이나 외부 데이터에서 다시 측정해야 한다.
원 실험은 YDF 0.15.0에서 실행했으므로 재학습할 때도 버전을 맞춰야 한다.

## 3. MMSE 미포함 모델

### 제안 모델

**28일·8개 입력 Sequence Transformer**

최근 28일의 활동·수면 기록을 여덟 가지 형태로 구성해 각각 예측한 뒤, 그
결과를 평균하는 모델이다. MMSE가 들어 있는 파일은 전혀 사용하지 않는다.

### 전처리 방식

- 활동과 수면에서 얻은 생리 신호 113개만 사용한다.
- 모든 사람에게 같은 기준을 적용해 최근 28개 관측으로 여덟 가지 입력 묶음을
  만든다.
- 날짜, 원본 행 번호, 관측 일수, 결측 개수, 기기 미착용 정보처럼 실제 건강
  상태보다 데이터 수집 환경을 나타낼 수 있는 값은 입력에서 제외한다.
- 값이 한쪽으로 크게 치우치는 일부 변수는 미리 정한 규칙으로 변환한다.
- 비어 있는 값은 중앙값으로 채우고, 지나치게 큰 값의 영향을 줄인 뒤 변수의
  단위를 맞춘다. 이때 필요한 기준은 매번 학습용 사람에게서만 계산한다.
- 한 사람에게서 만든 여덟 입력은 항상 모두 학습용이거나 모두 평가용이다.
- 여덟 번의 예측 확률을 평균해 그 사람의 최종 점수를 만든다.

### 데이터 분할 방식

- 최종 평가용으로 사람을 5개 묶음으로 나누는 과정을 5번 반복했다.
- 각 평가 안에서는 학습용 사람만 다시 4개로 나누고 이를 2번 반복해, 보조
  모델을 추가할지 결정했다. 최종 평가 대상자의 정답은 이 결정에 쓰지 않았다.
- 학습을 몇 번 반복할지(epoch)는 현재 학습용 사람의 20%를 임시 확인용으로
  떼어 정한 뒤, 결정된 횟수로 학습용 전체를 다시 학습했다.
- 각 사람에게서 얻은 다섯 평가 점수를 평균해 최종 ROC-AUC를 계산했다.
- 결과의 불확실성을 확인하기 위해 사람 단위 재추출을 5,000번 수행해 95%
  신뢰구간도 계산했다.

### 모델 선택 / 하이퍼파라미터 튜닝

이 Transformer의 구조는 이전 웨어러블 실험 결과를 바탕으로 평가 전에
고정했다. Ridge, Elastic-Net, RBF-SVM, CatBoost도 보조 모델로 시험했지만,
학습 데이터 안에서 ROC-AUC가 0.005 이상 좋아지고 여러 분할에서 일관되게
이길 때만 추가하도록 엄격하게 제한했다.

보조 모델을 더했을 때 성능이 꾸준히 좋아지지 않았으므로, 최종적으로는
**Sequence Transformer 단독**을 제안한다. 일부 분할에서 보조 모델을 더한
결과는 0.6172였고, 처음부터 고정해 둔 Transformer 단독은 0.6293이었다.

| 항목 | 값 |
| --- | --- |
| 사용 기간 / 입력 묶음 | 28일 / 8개 |
| 입력 변수 | 113개 |
| Transformer width | 64 |
| Encoder | 2 layers, 4 heads |
| Feed-forward width | 128 |
| Dropout | 0.25, prediction head 0.30 |
| Optimizer | AdamW |
| Learning rate / weight decay | `3e-4` / `2e-4` |
| Batch size | 32 |
| 최대 epoch / patience | 120 / 16 |
| 배포 full-refit 선택 epoch | 13 |

두 집단의 인원 차이를 완화하기 위해 학습 시 집단별 가중치를 조금 다르게
주었고, 모델이 지나치게 확신하지 않도록 약한 label smoothing을 적용했다.
학습 횟수와 보조 모델 선택에는 최종 평가 대상자의 정답을 사용하지 않았다.

### 최종 결론 및 코멘트

- 사람별 예측을 평균한 ROC-AUC: **0.629307**
- 사람 단위 재추출로 계산한 95% 신뢰구간: **[0.534346, 0.724477]**
- 분할 반복별 AUC 평균: **0.595525**
- 분할 반복별 AUC 표준편차: **0.020109**
- 직접적인 데이터 누수 점검: 통과
- MMSE 데이터 사용: 없음

직접적인 데이터 누수가 없는 완료 결과 중 MMSE를 사용하지 않은 모델로는 가장
높은 성능이다. 이전 Transformer의 0.6254와 비슷한 0.6293이 새로운 분할에서도
나왔다는 점은 긍정적이다. 하지만 반복별 평균은 약 0.596이고 95% 신뢰구간도
넓다. 따라서 현재 단계에서는 임상적으로 안정적인 선별 모델이라기보다,
웨어러블 정보만으로 두 집단을 어느 정도 순서화할 수 있다는 제한적인 신호로
보는 편이 안전하다.

MMSE 포함 모델과 약 0.154 차이가 난다는 점을 보면, 이 데이터에서는 MMSE가
분류에 매우 중요한 정보라는 것을 알 수 있다. 웨어러블 모델을 개선하려면 같은
141명 안에서 모델을 계속 바꾸기보다, 현재 설정을 고정하고 새로운 참여자나 더
긴 기간의 데이터에서 다시 확인하는 것이 우선이다.

## 4. 최종 제안

1. **MMSE를 사용할 수 있다면** Google YDF의 두 모델 결합형을 권장한다.
   현재 개발 단계 ROC-AUC는 0.7834다.
2. **MMSE를 사용할 수 없다면** 최근 28일 활동·수면 기록을 사용하는
   Sequence Transformer 단독 모델을 권장한다. 현재 ROC-AUC는 0.6293이며,
   아직 높은 임상 성능을 기대하기는 어렵다.
3. 두 모델은 특정 판정 기준값이 아니라, CN과 MCI·Dem을 구분하는 순위가
   얼마나 정확한지를 나타내는 ROC-AUC로 골랐다. 실제 판정 기준값은 사용
   목적이 정해진 뒤 별도로 선택해야 한다.
4. 다음 단계에서는 같은 141명으로 후보를 더 탐색하기보다 현재 모델을 그대로
   고정하고, 새로운 사람 분할이나 외부 참여자 데이터로 성능을 확인하는 것이
   좋다.
