# Binary_Wearable_ConvBiLSTM_NoMMSE (웨어러블만, MMSE 제외)

## 한 줄 요약

Activity·Sleep 웨어러블 기록**만**으로 `CN`(정상) vs `MCI+DEM`(인지저하)을
구분합니다. **MMSE(인지검사)는 절대 사용하지 않습니다.** 팀 최종 보고서에서
"이진 분류 중 유일하게 의미 있는 정확도"를 낸 **Conv1D+BiLSTM** 구조를
누수 없이 재현하고, 안정적인 트리·회귀 모델과 함께 묶었습니다.

## 왜 이렇게 만들었나 (아주 쉽게)

지금까지의 실험과 팀 보고서에서 확인된 사실은 다음과 같습니다.

- 웨어러블만으로 인지저하를 맞히는 건 **원래 매우 어렵습니다.** 예전에 나온
  92% 같은 높은 숫자는, 같은 사람의 다른 날짜 데이터가 학습과 평가에 같이
  들어가는 **데이터 누수** 때문이었습니다. 사람 단위로 제대로 나누면(같은
  사람은 학습 또는 평가 한쪽에만) 대부분의 모델이 거의 찍기 수준으로
  떨어졌습니다.
- 그중에서 **Conv1D+BiLSTM**만 그나마 나았습니다(보고서 기준: 검증 33명에서
  정확도 0.84, 균형정확도 0.71). 이때의 성공 비결은 ① **특징을 적게** 쓰고
  ② **시간 흐름(며칠간의 변화)** 을 보고 ③ **강한 규제(dropout·L2)** 로
  과적합을 막고 ④ **한 사람의 여러 창을 평균**해서 판단한 것이었습니다.
- 다만 그 모델조차 내부 교차검증 AUC는 0.49로 낮아, 0.84는 "작은 검증셋에서
  운이 좋았던 최고값"에 가깝습니다.

그래서 이 폴더는 그 **성공 비결 4가지를 그대로** 따르되, 신경망 하나에만
기대지 않고 **안정적인 표(tabular) 모델을 함께** 써서 결과가 들쭉날쭉하지
않도록 했습니다.

## 무엇을 입력으로 쓰나

한 사람당 딱 한 줄(피험자 단위)로 만듭니다.

- **시간 흐름용(Conv1D+BiLSTM)**: 각 사람에게 동일하게 **7일짜리 창을 8개** 뽑아
  56개 생리 채널(활동량·수면단계·심박·HRV·수면호흡 등)의 흐름을 봅니다. 창
  개수를 모두 똑같이 맞춰서, 기록이 긴 사람이 학습을 지배하지 못하게 했습니다.
- **요약용(트리·회귀)**: 최근 35일에서 각 채널의 **중앙값·IQR·추세** 3가지만
  뽑아 요약합니다(56×3=168개 후보). 여기서 각 fold 안에서만 최대 30개를
  고릅니다.

**절대 넣지 않는 것**: MMSE·진단명·이메일·아이디·날짜·기록일수·착용여부 등.
이름에 `mmse`가 들어가면 즉시 거부하는 안전장치가 있습니다.

## 모델 구성

- `conv_bilstm`: `Conv1D(32) → BiLSTM(8, 양방향) → Dense(8) → Dense(1)`,
  dropout 0.5, L2(weight decay) 5e-3, 클래스 가중치 적용. 각 사람의 8개 창
  확률을 평균해 그 사람의 점수로 씁니다. (보고서의 우승 구조와 동일)
- `gbt` / `logreg` / `rf`: HistGradientBoosting, L2 로지스틱 회귀, 랜덤포레스트.
  모두 클래스 가중치로 불균형을 보정합니다.
- 네 모델의 확률을 **내부 교차검증 성능(균형정확도)** 에 비례해 가중 평균합니다.
  약한 모델은 가중치가 0에 가까워지고, 다 약하면 단순 평균으로 물러섭니다.

## 누수를 막는 방법

- 모든 분할은 **사람 단위**입니다(같은 사람이 학습·평가에 동시에 못 들어감).
- 결측 대치·정규화·특징 선택·앙상블 가중치·임계값을 **그 fold의 학습
  데이터에서만** 정합니다.
- 평가는 **5-겹 × 2-반복 중첩 교차검증**으로 하고, fold마다 다른 점수 크기를
  맞추려 확률이 아니라 `확률 − 임계값` 여백을 평균합니다.
- 검증 33명은 예측을 먼저 저장(+SHA-256 동결)한 **뒤에야** 정답을 열어 한 번만
  채점합니다. 학습·검증에 겹치는 사람이 있으면 즉시 중단합니다.

## 목표와 정직한 기대치

- 목표: 정확도 **0.90 이상**, 균형정확도 **0.80 이상**.
- 정직한 예상: 위 목표는 **희망 목표**이며 코드가 보장하지 않습니다. 같은
  데이터를 다룬 모든 선행 연구가 사람 단위로 엄격히 평가하면 균형정확도
  약 0.71이 사실상 천장이었습니다. **웨어러블만으로 0.90/0.80은 도달하기
  매우 어렵다**는 점을 전제로 결과를 해석하세요. 이 폴더의 값어치는 "누수
  없이 정직하게 얼마가 나오는가"를 보여주는 데 있습니다.
- 그래서 정확도 하나만 보지 말고 **균형정확도·인지저하 재현율·CN 특이도·
  ROC-AUC·혼동행렬·부트스트랩 신뢰구간**을 함께 봐야 합니다. 검증 33명은 CN이
  26명이라 **전부 CN으로 찍어도 정확도 0.79**가 나오는 함정이 있습니다.

## 실행 방법 (Colab, base.ipynb)

루트 `base.ipynb` 셀 2에서 아래만 바꿉니다.

```python
USER_FOLDER = "SangHyo"
RUN_FILE = "Binary_Wearable_ConvBiLSTM_NoMMSE/run.py"
```

기본 모드는 `full`입니다. 빠른 배선 확인만 하려면:

```bash
python run.py --mode smoke --output-dir /content/drive/MyDrive/tmp_convbilstm_smoke
```

### 필요한 실행 환경 (중요)

- **A100 GPU 런타임을 권장합니다.** Conv1D+BiLSTM은 GPU에서 학습합니다.
  **GPU가 없으면 신경망은 자동으로 빠지고 표 모델만** 돌아가며, 그 경우
  성능은 거의 찍기 수준으로 낮아집니다(신경망이 이 실험의 핵심이라서 그렇습니다).
- 고용량 RAM은 필요 없습니다. 표 모델은 CPU만으로 충분합니다.
- 예상 시간: 신경망을 포함해도 A100에서 **1시간 이내**로 끝나도록 맞췄습니다
  (중첩 교차검증에서 작은 신경망을 여러 번 학습). 6시간 안전 상한을 둡니다.

결과는 `/content/drive/MyDrive/Binary_Wearable_ConvBiLSTM_NoMMSE_result/<UTC_실행ID>/`
아래에 실행마다 새 폴더로 저장됩니다.
