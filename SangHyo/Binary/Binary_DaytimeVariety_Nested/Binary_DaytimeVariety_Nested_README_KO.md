### 수용 기준
| # | 기준 |
|---|---|
| **A** | `Δ_features = P − B0` paired 95% CI 하한 > 0 ← **헤드라인** |
| B | 절대 merged AUC ≥ 0.70 |
| C | 관측 max > K=2 permutation null 95백분위 |
| D | subject bootstrap 95% CI 하한 ≥ 0.60 |
| **E** | falsifier 1개 이하 실패 |

"목표 달성" = B+C+D. "유의한 진전" = A. "방어 가능한 복제" = E. **다섯 다 보고한다.**

> **B0 는 중립 baseline 이 아니라 1차 탐색의 승자다.** Δ 는 구조적으로 P 에 불리하고,
> 그래서 D블록 자체를 falsifier 로 따로 검증한다. 특히 (a)는 무너질 가능성이 높다
> — 1차 감사에서 `low_resid(log)` 의 Dem AUC 가 0.845 → **0.662** 였다.
> 무너지면 정직한 결론은 **"치매에서 주간 활동량 감소"**이지 "다양성 감소"가 아니다.

## 실행 전 검증

**실제 `Data/` 메타데이터** (모델 학습 없음): `met_1min` 12,183일 전부 정확히 1440점,
`activity_day_start` 전부 04:00 / 하루 24.0h(→ 분 index ↔ 시각 매핑 유효),
착용률 중앙값 0.999·게이트 0.8에서 99.5% 유지·전원 35일 이상, MET 행렬 70MB·파싱 1.9초.

**합성 데이터 배선 테스트** 통과 (전 13셀 완주, 결정성 해시 일치, CJK 글리프 경고 0).
그 과정에서 잡은 것: 교란변수가 상수일 때 **잔차화가 항등변환이 되어 falsifier 가 조용히
"통과"로 집계되던 구멍** → "판정 불가(N/A)"로 분리하고 기준 E 를 판정 가능한 것 기준으로
평가하도록 수정. (배선 테스트의 AUC 는 합성 신호라 성능이 아니다.)

## 정직한 기대치 — **성공 확률 15~25%**

필요한 A_MCI 0.609 → 0.653 은 Hanley–McNeil SE(0.0488) 기준 **0.9 SE**에 불과하다.
등상관 예산 계산상 ρ≥0.4면 특징을 몇 개 더해도 0.70에 못 간다(점근 0.669).
`W1_min` 이 `low_SD` 와 ρ=0.43 이라 이 경계에 가깝다.

**미달해도 남는 것**: `Δ_features` 는 새 구성개념의 순수 증분이라 0이어도 확정적 지식이고,
falsifier 4종은 D블록(0.6528)이 **분산 마커인지 수준 마커인지**를 가른다. 1차의 야간-null
결과와 합치면 이 데이터셋에서 웨어러블-only 신호의 위치와 상한을 축 단위로 규명한 것이 된다.
