## 2. 논문 미보고 사항의 산술적 복원 — 평가집단은 33명이다

이것이 본 재현의 가장 중요한 발견이다. 논문은 분할단위·평가단위를 명시하지 않았으나,
**보고된 지표값들이 정수비로 완전히 분해되어 평가집단이 유일하게 결정된다.**

### 2-1. 분모 복원

| 보고값 | 정확한 분수 | 함의 |
| --- | --- | --- |
| Accuracy 0.787879 (1D-CNN) | 26/33 = 0.7878787… | 평가표본 **33개** |
| Accuracy 0.818182 (LSTM, Bi-LSTM) | 27/33 = 0.8181818… | 평가표본 **33개** |
| Accuracy 0.6970 (RF, XGB) | 23/33 = 0.696969… | 평가표본 **33개** |
| Recall 0.8571 (1D-CNN) | 6/7 | 양성 **7개** |
| Recall 0.7143 (RF, XGB) | 5/7 | 양성 **7개** |
| Recall 0.1428 (LSTM, Bi-LSTM) | 1/7 | 양성 **7개** |

→ **평가집단 = 33개 표본, 그중 양성 7개.**

### 2-2. 혼동행렬 완전 복원

`F1 = 2TP / (2TP + FP + FN)`로 교차검증하면 각 모델의 혼동행렬이 **유일하게** 결정되고,
보고된 F1과 정확히 일치한다.

| 모델 | TP | FN | FP | TN | Accuracy | Recall | Precision | F1(계산) | F1(논문) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Random Forest | 5 | 2 | 8 | 18 | 23/33 = .6970 | 5/7 = .7143 | 5/13 = .3846 | 10/20 = **.500** | 0.5 ✅ |
| XGBoost | 5 | 2 | 8 | 18 | 23/33 = .6970 | 5/7 = .7143 | 5/13 = .3846 | 10/20 = **.500** | 0.5 ✅ |
| LSTM | 1 | 6 | 0 | 26 | 27/33 = .8182 | 1/7 = .1429 | 1/1 = 1.000 | 2/8 = **.250** | 0.25 ✅ |
| Bi-LSTM | 1 | 6 | 0 | 26 | 27/33 = .8182 | 1/7 = .1429 | 1/1 = 1.000 | 2/8 = **.250** | 0.25 ✅ |
| 1D-CNN | 6 | 1 | 6 | 20 | 26/33 = .7879 | 6/7 = .8571 | 6/12 = .5000 | 12/19 = **.6316** | 0.63 ✅ |

다섯 모델 모두 Accuracy·Recall·F1이 **동시에** 정합한다. 우연의 일치가 아니다.

### 2-3. 평가집단의 정체

실제 데이터에서 **AI-Hub Validation 분할은 정확히 33명이며 CN 26 / MCI 4 / Dem 3,
즉 음성 26 / 양성 7이다.** 복원된 평가집단(33개, 양성 7개)과 **완전히 일치**한다.

따라서 다음이 강하게 뒷받침된다.

1. **평가단위는 피험자다** (일별 행이 아니다).
   - 행 단위였다면 test 행 수가 약 12,183 × 0.2 ≈ 2,437이 되어 Accuracy가 `k/33` 형태로
     떨어질 수 없다.
2. **"80:20"은 AI-Hub 공식 Training/Validation 분할이다** (141 : 33 = 81.0 : 19.0).
   - 174명을 `test_size=0.2`로 무작위 분할하면 test는 35명이 되어 33명이 나오지 않는다.
3. **원 논문의 분할은 이미 피험자 독립적이다.** RF/XGB는 피험자별 평균으로 1인 1행이 되고,
   딥러닝은 1인 1시퀀스이므로, 같은 사람의 날짜가 train/test에 동시에 들어가는
   전형적인 행 단위 누수는 **발생하지 않았다.**

### 2-4. 그렇다면 원 논문의 실제 방법론적 약점은 무엇인가

행 단위 누수가 아니라 다음 네 가지다.

1. **고정된 단일 분할, 극소 평가표본**: 양성 7명. 한 명이 바뀌면 Recall이 14.3%p 움직인다.
   1D-CNN(6/7)과 LSTM(1/7)의 차이는 **양성 5명**의 차이일 뿐이다.
2. **모델 선택이 그 33명 위에서 이루어짐**: 다섯 모델을 같은 33명에서 평가한 뒤 최고
   성능인 1D-CNN을 "최종 분류기로 채택"했다. 이것은 test set을 모델 선택에 사용한 것이며,
   보고된 0.810 AUC에는 **5개 중 최댓값을 고른 선택 편향**이 포함되어 있다.
3. **하이퍼파라미터 탐색 범위 불명**: Random Search + 5-Fold CV를 train 141명 안에서만
   했는지, 174명 전체에서 했는지 논문에 없다. 후자라면 test 정보가 새어 들어간다.
4. **정규화 적합 범위 불명**: "정규화 후 3차원 텐서"의 스케일러를 전체 데이터에 적합했는지
   train에만 적합했는지 명시가 없다.

> 이 절의 결론은 사용자 프롬프트의 사전 정보("행 단위 80:20 분할이면 피험자 중복 경고")와
> 다르다. 실제 데이터로 검증한 결과 **원 논문은 행 단위 분할을 하지 않았을 가능성이 매우
> 높다.** 다만 논문이 이를 명시하지 않았으므로 본 재현은 행 단위 변형도
> `assumption_variant_random_row_holdout`으로 함께 구현하여 누수 크기를 정량화한다.

## 3. 원 논문 보고 성능 (비교 기준값)

학위논문 표 13·14·17 = 학술지 논문 표 10·11·14 (완전 동일).

| Model | Accuracy | AUC | F1-Score | Recall |
| --- | ---: | ---: | ---: | ---: |
| Random Forest | 0.6970 | 0.7225 | 0.50 | 0.7143 |
| XGBoost | 0.6970 | 0.6374 | 0.50 | 0.7143 |
| LSTM | 0.818182 | 0.527473 | 0.25 | 0.1428 |
| bi-LSTM | 0.818182 | 0.390110 | 0.25 | 0.1428 |
| **1D-CNN** | **0.787879** | **0.810440** | **0.63** | **0.8571** |

주: 결론부 표 17/14는 같은 값을 소수 둘째 자리로 반올림한 것이다(1D-CNN Accuracy를
0.78로 표기). 본 재현의 비교 기준은 정밀도가 높은 표 13·14 / 10·11 값을 사용한다.

**AUC 분모 참고**: `LSTM AUC = 0.527473 = 96/182`, `bi-LSTM = 0.390110 = 71/182`이며
182 = 7 × 26 = 양성수 × 음성수다. Mann–Whitney U 통계량이 정수로 떨어지므로,
**AUC 역시 33명 피험자 단위로 계산되었음**이 독립적으로 확인된다.

## 5. 전처리 수행순서 (본 재현)

### 실험 A (`paper_reported_reconstruction`)
```
1. CSV 로드 (activity, sleep, mmse, label)
2. EMAIL → subject_id 해시
3. 라벨 병합 (mmse의 DIAG_NM, EMAIL 기준) → 이진화 CN=0 / MCI·Dem=1
4. 제거 변수 목록 drop (논문 목록 그대로, errors='ignore')
5. 분기
   5a. tabular : groupby(subject).mean(numeric_only=True)  ← 논문 코드 그대로
   5b. sequence: 날짜 파생 → 정렬 → (N, T, F) 텐서 + 패딩
6. 분할 (official_partition 기본)
7. 정규화  ← scaler_scope 설정에 따라 train-only / all-data 두 변형
8. 학습 → 33명 평가
```

### 실험 B·C (`leakage_controlled_*`, `nested_*`)
```
1–5까지 동일 (단, 6·7 순서가 뒤바뀜)
6. 피험자 단위 분할 (StratifiedGroupKFold)
7. fold의 학습부분에서만 imputer/scaler/selector fit  ← 강제
8. 시퀀스는 분할 이후에 각 split 내부에서만 생성
9. 학습 → 피험자 단위 평가
```

## 6. 평가지표

| 구분 | 지표 |
| --- | --- |
| 주 평가단위 | **피험자** |
| 주 지표 | ROC-AUC, PR-AUC, balanced accuracy, sensitivity, specificity, F1, Brier score |
| 보조 | accuracy, confusion matrix, calibration curve, 일별/시퀀스 단위 metric |
| 통합 방식 | 피험자별 예측확률 **평균** (기본), 중앙값·다수결은 민감도 분석 |
| 불확실성 | 피험자 단위 bootstrap 95% CI, fold 간 표준편차 |

임계값 정책:
- 실험 A: 0.5 (논문 미보고 → 가정)
- 실험 B: 0.5 고정 (사전 고정)
- 실험 C: **inner CV에서만** 선택, outer test는 절대 미사용

## 9. 본 재현이 "exact reproduction"이 아닌 이유

다음이 논문에서 확인되지 않으므로, 본 작업은 **reported-method reconstruction**이다.

- 다섯 모델 중 **세 개(LSTM/Bi-LSTM/1D-CNN)의 신경망 구조가 전혀 보고되지 않았다.**
  층 수, hidden units, kernel size, filter 수, dropout, optimizer, learning rate,
  epoch, batch size 중 **단 하나도** 명시되지 않았다.
- Random Forest 하이퍼파라미터가 **전혀** 보고되지 않았다.
- 시퀀스 길이·패딩 규칙이 보고되지 않았다.
- random seed가 보고되지 않았다.
- 분할단위가 명시되지 않았다(§2에서 복원했으나 논문 진술은 아니다).

따라서 실험 A의 산출물에는 항상
`reproduction_class: "reported-method reconstruction"` 태그가 붙는다.
