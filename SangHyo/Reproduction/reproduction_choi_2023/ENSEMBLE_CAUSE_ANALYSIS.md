## 1. GBC: 튜닝 추첨 분산 — 실측으로 종결

**방법**: pycaret 3.3.2 소스에서 gbc 튜닝 그리드를 추출해, 논문 절차와 동일한
RandomizedSearchCV(n_iter=10, 10-fold, AUC)를 **탐색 시드만 바꿔 8회** 반복.
데이터·분할은 faithful A(seed 42)와 동일.

| 탐색 시드 | best CV AUC | 홀드아웃 AUC |
| --- | --- | --- |
| rs0 | **0.9118** | 0.9133 |
| rs1 | 0.8440 | 0.8453 |
| rs2 | 0.8709 | 0.8583 |
| rs3 | 0.8716 | 0.8743 |
| rs4 | 0.8573 | 0.8549 |
| rs5 | 0.8668 | 0.8717 |
| rs6 | 0.8722 | 0.8632 |
| rs7 | **0.9141** | 0.9128 |
| (n_iter=60) | 0.9057 | 0.9032 |

- 분포: **min 0.8440 / 중앙값 0.8713 / max 0.9141**
- Colab seed42의 0.8737은 중앙값과 0.0024 차이 — **전형적인 추첨**
- 논문의 0.9061은 분포 범위 안이며, **8회 중 2회가 0.90 이상 도달**
- 좋은 추첨(rs0·rs7)의 홀드아웃은 0.9128~0.9133 → 논문 gbc 홀드아웃 0.9161과 −0.003 수준

**결론(실측)**: gbc 편차는 재현 실패가 아니라 `n_iter=10` 랜덤서치의 추첨 분산이다.
논문은 상위 ~25% 추첨을 뽑았고, 우리 seed 42는 중앙값 추첨을 뽑았다.

## 2. Stacking: 우발적 피험자 분리 — 5단계 인과 사슬 전부 계측

**현상**: 논문은 stacking을 최저(AUC 0.6539)로 보고. 우리 A 실행들은 0.91대(정상),
1차 재현의 C fold 4개는 0.59~0.88 + F1=0(붕괴). 붕괴 케이스(1차 C_fold0)를 로컬에서
동일 시드로 재현(AUC 0.6601)한 뒤 내부를 계측했다.

**사슬 (모든 고리 측정값)**

| # | 고리 | 붕괴 케이스 | 정상 케이스 |
| --- | --- | --- | --- |
| 1 | 학습 행 순서가 만드는 메타 CV의 자기피험자 노출률* | **3.73%** | **100%** |
| 2 | 메타러너 학습 입력(OOF)의 특성별 AUC | **0.5025 / 0.5016 / 0.5005 / 0.5095 / 0.5064** | (예측시점 0.877~0.913) |
| 3 | 메타 LR이 학습한 계수 | [0.03, −0.36, −0.26, 0.84, 0.08], 절편 −0.693 | [2.19, 2.06, 5.46, 1.32, −0.67], 절편 −5.11 |
| 4 | 출력 분포 | [0.312, 0.414]로 압축, 0.5 초과 0% → F1=0 | [0.006, 0.994] 전 범위 |
| 5 | 복제 검증 | 사슬만으로 재구성한 스택 = **0.6602** (파이프라인 실측 0.6601) | — |

\* sklearn `StackingClassifier(cv=5)`는 내부적으로 `StratifiedKFold(shuffle=False)`를
쓴다. 학습 데이터가 **환자별로 묶인 순서**(우리 일일 테이블은 patient_id 정렬;
`StratifiedKFold.split`이 반환하는 인덱스는 정렬돼 있어 C fold 조건의 학습행이 이 순서를
유지)면 연속 블록 fold가 피험자를 거의 통째로 갈라, 메타특성 생성용 OOF 예측이
**사실상 피험자 독립 예측**이 된다. 반대로 `train_test_split`/pycaret 내부 분할은
행 순서를 섞으므로(실측: pycaret X_train 인덱스 비정렬, 노출률 100%) OOF가 같은
피험자 누수의 혜택을 받아 강한 메타특성이 나온다.

**해석(측정에서 직접 따라옴)**: 절편 −0.693 = logit(0.365) — 우연 수준 입력을 받은
LR이 기저율(시험 CI 비율 0.365)을 출력하도록 수렴한 것. 붕괴 스태킹의 AUC 0.59~0.88은
잔존 미세 신호의 우연한 배열이다.

**논문과의 연결(추정, 검증 불가)**: 논문의 stacking 0.6539는 붕괴 모드의 관측 범위
(0.59~0.88) 안에 있다. 논문 파이프라인에서 메타 CV에 environmental하게 환자 블록 순서가
들어갔다면(원자료 CSV 자체가 환자별로 묶여 있음) 같은 붕괴가 일어난다. 다만 논문의
F1 0.3398은 우리 붕괴 케이스들(F1=0.0)과 달리 부분 붕괴 형태라, **모드는 재현되지만
정확한 수치 경로는 논문 코드 없이 확정할 수 없다.** PyCaret 3.0.0의 내부 행 순서 처리는
해당 버전이 현 환경에 설치 불가라 미검증이다.

**부수 발견**: 스태킹의 내부 CV가 우발적으로 피험자 분리를 수행하면서, 이 파이프라인의
"진짜" 일반화 수준(우연)을 논문 Table 6 안에서 유일하게 드러낸 항목이 stacking이었다.
2×2 실험의 조건 B(피험자 독립, AUC 0.4838)와 정확히 같은 이야기다.

## 3. 최종 조립: gbc 추첨만 교체한 faithful A (모델 저장본)

seed 42 파이프라인에서 **gbc 한 자리만** rs7 추첨(논문과 같은 n_iter=10 절차가 실제로
뽑은 구성: subsample 0.7, n_estimators 180, max_depth 10, learning_rate 0.05,
min_samples_leaf 2, min_impurity_decrease 0.02)으로 고정하고 나머지는 그대로 재실행.

| 모형 | 논문 AUC | 이번 재현 | 차이 | (교체 전) |
| --- | --- | --- | --- | --- |
| voting | .9193 | **.9141** | **−.0052** | −.0141 |
| gbc | .9161 | **.9128** | **−.0033** | −.0477 |
| xgboost | .9132 | .8989 | −.0143 | −.0160 |
| lightgbm | .8971 | .8913 | −.0058 | −.0058 |
| et | .8877 | .8767 | −.0110 | −.0122 |
| rf | .8781 | .8740 | −.0041 | −.0045 |
| stacking | .6539 | .9163 | +.2624 | +.2552 |

- **gbc 추첨 하나를 바꾸자 voting 편차가 −.0141 → −.0052로 줄었다** — voting 편차의
  원인이 gbc 추첨이었음을 실측으로 확인
- F1: voting .7780(논문 .7833), Acc .8462(논문 .8503)
- gbc CV는 .9161(논문 .9061보다 +.0100 — 이번엔 우리 추첨이 더 좋음)
- Table 7(이 gbc 기준): 상위10 교집합 8/10, 1위 동일(sleep_breath_average)
- stacking은 정상 모드(.9163)로 저장 — 붕괴 모드는 §2에서 결정적으로 재현·설명됨

**저장 위치** (`RELOAD_RUN_ID` 호환 레이아웃, 로드 왕복 검증 완료 — 차이 1e-6):

## 4. "완벽 재현"의 한계 명시

- 논문 `session_id` 미보고 → 분할·탐색 난수가 걸린 수치(Table 5 사후, Table 6)의
  완전 일치는 원리적으로 불가능. 이번 조립은 **잔여 편차의 원인을 하나씩 실측으로
  제거해 도달 가능한 최근접점**(voting −0.0052)이다.
- stacking은 수치가 아니라 **모드**(붕괴/정상)가 갈리는 항목이며, 붕괴 모드는
  결정적으로 재현·설명됐지만 논문이 그 모드에 있었다는 것은 추정이다.
- gbc를 rs7 구성으로 고정한 것은 "논문 절차가 뽑을 수 있는 추첨 중 논문 결과에
  상응하는 것"의 명시적 선택이다(출처를 manifest에 기록). 논문 수치에 맞추기 위한
  선택이므로, 독립 재현 성능을 주장할 때는 seed 42 원본(voting .9052)을 쓰는 것이 맞다.

## 5. BCD 재사용 시 주의 (요청하신 모델 저장 관련)

저장된 A 모델은 **174명 전원의 데이터로 학습**됐다. 이 모델을 로드해 피험자 분할(B·D)
시험행을 평가하면 시험 피험자가 이미 학습에 포함돼 있어 피험자 독립 평가가 되지 않는다
(그 결과는 조건 A의 누수 성능으로 회귀한다). B·C·D는 기존 2×2 노트북처럼 fold마다
재학습해야 하며, 저장 모델의 정당한 용도는 외부 신규 데이터 예측, 중요도·앙상블 해부,
그리고 동일 홀드아웃 재검증이다.
